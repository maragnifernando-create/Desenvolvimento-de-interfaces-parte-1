Esse repositório tem como objetivo guardar e organizar as aplicações de sites feitos durante a
primeira parte da disciplina de desenvolvimento de interfaces

Os sites foram feitos a partir dos conteúdos apresentados nas aulas

Dentre eles:

- IHC (Interação Humano-Computador)
- Design Thinking e suas fases
- As 10 Heurísticas de Nielsen
- WCAG e Paleta de cores
- UX (User expirience) e UI (User interface)
