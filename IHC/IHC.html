Interação Humano - Computador

A Interação Humano-Computador (IHC) é estudo das relações entre pessoas e os computadores, relação essa que surgiu desde o desenvolvimento dos primeiros computadores. Ela surge a partir da interface do utilizador, que é formada por hardware e software, e utilizada na manipulação de alguns periféricos de computadores.

Importância:

A IHC é importante:

  • Para as interações das pessoas com a tecnologia diariamente, como uso de celular e computador, como também qualquer aparelho eletrônico
  • Para as indústrias que utilizam computadores e sistemas diariamente
  • Para a acessibilidade e suporte para pessoas com deficiência
  • Para ser uma parte muito importante para o sucesso de um software para os usuários finais
  • Para criar interfaces interativas e eficazes para dar suporte as comunidades

Características:

  1. Usabilidade: É fundamental já que garante que usuários de todos os tipos possam aprender e usar sistemas computacionais rapidamente. O sistema deve ser fácil de aprender e memorizar, seguro, eficiente, eficaz e agradável
  2. Experiência do usuário: É uma característica subjetiva que se concentra em como os usuários se sentem em relação ao sistema computacional ao interagir com ele. Nesse contexto, os sentimentos dos usuários são estudados individualmente para que desenvolvedores e equipes de suporte possam direcionar ações específicas a usuários específicos, a fim de evocar sentimentos positivos durante o uso do sistema. Os sistemas de IHC (Interação Humano-Computador) classificam os padrões de interação do usuário nas seguintes categorias e refinam ainda mais o sistema com base no padrão detectado: Características desejáveis: gratificantes, agradáveis, motivadoras ou surpreendentes Características indesejáveis: Frustrante, desagradável ou irritante
